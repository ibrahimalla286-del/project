# مشروع الويب الأول

مشروع بسيط يتكون من ثلاث صفحات (الرئيسية، ومن نحن، وتواصل معنا) مع تطبيق وسوم HTML الدلالية وجداول وقوائم ونماذج إدخال وتنسيق CSS مشترك.

## هيكل المشروع

* `index.html` - الصفحة الرئيسية
* `about.html` - صفحة من نحن
* `contact.html` - صفحة تواصل معنا (تتضمن نموذج اتصل بنا)
* `css/style.css` - ملف التنسيقات
